# Design System — ABONE Consulting

## Direction

Corporate-tech consulting aesthetic inspired by premium references (Finovate / Aeline style): bright lime accents, deep forest-black surfaces, generous whitespace, rounded geometry, full-bleed photography heroes.

## Fonts (Google)

- Display / headings: **Plus Jakarta Sans**
- Body / UI: **DM Sans**

## Color tokens

```css
--color-ink: #0C1F1A;
--color-forest: #143028;
--color-lime: #D4FF5E;
--color-lime-deep: #B6E63A;
--color-surface: #FFFFFF;
--color-mist: #F4F5F3;
--color-muted: #5F6B66;
--color-border: #DDE2DD;
```

## Components

- Pill CTAs with circular arrow action (`ArrowCta`)
- Soft section labels (uppercase micro-pills)
- Large radius cards (`rounded-[2rem]`)
- Full-bleed photo heroes with left-weighted dark overlay
- Glass chips only sparingly in the hero quick-nav strip

## Motion

- Hero entrance stagger
- Section reveal on scroll
- Arrow icon rotation on CTA hover
